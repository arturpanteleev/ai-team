# Чистая инициализация проекта

## Зачем

`ai-team init` безусловно изменяет `.gitignore`. Сразу после установки это
оставляет рабочее дерево грязным, поэтому baseline guard отклоняет первый
`ai-team run`. Базовый сценарий `init → run` должен работать без служебного
коммита пользователя.

## Что меняется

- По умолчанию `.ai-team/` добавляется в локальный
  `.git/info/exclude`, который не входит в рабочее дерево.
- Явный флаг `--write-gitignore` сохраняет прежнее поведение для команд,
  которым нужна разделяемая ignore policy.
- Парсинг аргументов `init` становится строгим и поддерживает флаги в любом
  порядке.
- E2E-сценарий проверяет чистый Git workspace непосредственно после `init` и
  запускает pipeline без ручного коммита `.gitignore`.

## Затронутые области

- `cmd/ai-team`: команда `init` и Git ignore helper.
- `e2etest`: сквозной сценарий первого запуска.
- `README.md`: CLI и поведение ignore policy.
- OpenSpec capabilities: `project-init`, `cli-interface`, `e2e-testing`.
