# Data/control separation remainder (OPS-8)

## Proposal

**ID**: OPS-8  |  **Trace**: audit Finding 5 (High), H-09; foundation #22 (prompt
delimiters)  |  **Priority**: P1

### ЧТО

Достроить data/control separation на **выходной** стороне контура доверия:
контроль-маркеры вердиктов/статусов не должны приниматься из data-display
регионов (fenced code blocks, blockquotes) и из чужих event-пространств
адаптеров. #22 закрыл вход (untrusted delimiters в промпте), на выходе
остались кейсы, где «цитируемое»/«примерное» содержимое, созданное агентом,
может быть прочитано контроллером как управляющий сигнал.

### ПОЧЕМУ

Контур доверия = вердикты ревьюеров/тестеров/верификаторов + статусы BLOCKED.
Если агент (или untrusted-содержимое в его артефакте) приводится в виде
`**Verdict:** REJECTED` внутри код-фенса/цитаты как пример, контроллер сейчас
может принять это за настоящий вердикт. Плюс каждый новый адаптер (ADP-1/2)
добавляет поверхность разбора stdout — её надо закрывать общим правилом: только
собственные event-типы адаптера считаются control.

### Скоуп

1. `pkg/verdict`: функция исключения data-регионов (fenced blocks, blockquote);
   применение в `Parse`, `FromOutputsContract`, `ReadBlocked[Since]`.
2. Адаптеры: типизированный разбор только своих event-типов (`turn.completed`,
   `result`) + тесты на model-mimic JSON (чужие типы игнорируются).
3. OpenSpec delta.

### Критерии приёмки

- Маркер вердикта/статуса внутри fenced code block или blockquote НЕ читается
  как control (Parse возвращает None; contract-стадия — ошибка «маркер
  отсутствует», если вне регионов маркера нет).
- Несколько маркеров считаются только из control-регионов.
- Адаптеры игнорируют JSON-строки чужих типов; последний реальный
  `turn.completed`/`result` остаётся источником usage.
- Промпт-сторона (#22) не регрессирует.
- `go build ./...`, `go vet`, `gofmt -l` чистые; `go test ./...` зелёные
  (кроме 2 известных e2e baseline); `make specs` 71/71.

### Похожее / альтернативы

- Жёсткая рамку `<<<VERDICT>>>`/`<<</VERDICT>>>` вокруг вердикта: сильнее, но
  ломает все артефакты/агентов/инструкции сразу; в этом change не меняем
  контракт формата, а закрываем конкретный класс ошибок толкования.
- Положиться на линию-якорность и «модель разберётся»: уже недостаточно —
  это и есть «remainder» из DoD OPS-8.
