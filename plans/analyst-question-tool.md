# Analyst question tool (аналитик не может спросить)

Статус: idea

## Задача

Баг-противоречие: промпт аналитика требует задавать уточняющие вопросы при
неоднозначности задачи, но runtime деняет инструмент `question`
(`agentcli.go`: `"question": "deny"`). Единственный выход аналитика — BLOCKED
и перезапуск.

## Ценность для продукта

Качество требований — вход всего конвейера: если аналитик не может спросить,
он додумывает или останавливает run. Починка превращает grill-me фазу из
декорации в работающий механизм: меньше переделок на поздних этапах, меньше
пустых прогонов. Дешёвое изменение с непропорционально большим эффектом.

## Рекомендации по реализации

- разрешить `question` для интерактивного TTY-режима (вопрос через prompter);
- в non-TTY — fail-closed как сейчас (BLOCKED с текстом вопроса), либо
  вопрос как pending approval типа `request_information`;
- проверить, что deny-list остаётся для остальных агентов (coder не должен
  спрашивать).

## Как проверить

1. Интерактивный run: аналитик задал вопрос → получил ответ → продолжил.
2. Non-interactive: BLOCKED с явным текстом вопроса, exit code 2.
3. Coder/reviewer по-прежнему не имеют инструмента question.
