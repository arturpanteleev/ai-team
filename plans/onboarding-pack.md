# Onboarding pack (туториал, демо-репо, troubleshooting)

Статус: идея
Источник: docs/audits/2026-08-05-technical-audit.md «Documentation coherence 4/10»

## Задача

Пакет входа для нового пользователя: 10-минутный tutorial с ожидаемым выводом
на каждом шаге, скрипт демо-репозитория (локальный bare remote + моки),
страница troubleshooting с реальными ошибками и решениями.

## Ценность для продукта

Сейчас первый запуск нового человека — это исследование: README честен, но
между «init» и «PR создан» много точек, где без контекста непонятно, что
происходит и нормально ли это. Документация coherence оценена аудитом в
4/10 — и это метрика оттока: каждый провал первого запуска = потерянный
пользователь навсегда. Туториал с ожидаемым выводом превращает установку в
предсказуемый успех; troubleshooting съедает класс повторяющихся вопросов;
демо-репо позволяет попробовать продукт, не трогая свои проекты. Это
конверсия интереса в использование.

## Рекомендации по реализации

- tutorial: чистая машина → init → fast-профиль (см. workflow-profiles) →
  фича до PR на локальном bare remote; скриншоты/вывод каждого шага;
- `scripts/demo-repo.sh`: генерирует безопасное окружение для пробы
  (включая mock-хоста — после adapters-layer);
- troubleshooting: собирать из реальных вопросов/ошибок, начать с топ-10;
- связать с docs/ARCHITECTURE как корнем навигации.

## Как проверить

1. Свежая машина: прохождение tutorial без отклонений от описанного вывода.
2. Демо-скрипт идемпотентен: повторный запуск чинит, а не ломает.
3. Каждая ошибка в troubleshooting воспроизводима по инструкции.
